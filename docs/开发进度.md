# 开发进度文档 ——《幻境之门：梦境旅途》

> 最终状态：**全部 8 个阶段完成**，游戏可完整通关。

## 阶段一：项目初始化与基础架构 ✅

- Vite 5 + React 18 + TypeScript 5 + Three.js（R3F v8）项目骨架。
- 分层架构确立：
  - **数据层** `levels/`（纯数据关卡定义，视觉网格与行走节点分离）
  - **逻辑层** `systems/`（图论寻路、机关状态机、存档 —— 零渲染依赖）
  - **渲染层** `three/`（R3F 组件，每帧从引擎读取状态）
  - **界面层** `ui/`（zustand 驱动，与游戏逻辑完全解耦）
- 核心抽象设计完成：`GroupDef`（视觉网格 + 行走节点 + 机关状态）、端口重合连接规则。

## 阶段二：3D 场景与建筑系统 ✅

- 网格工厂 `primitives.ts`：14 种参数化几何（拱门/阶梯/尖塔/方尖碑/灯柱等），几何与材质全局缓存。
- 梦幻环境：三段渐变天空穹顶（着色器）、漂移云海、双色调波纹水面、悬浮岛 / 倒挂岛 / 遗迹 / 花草 / 灯柱装饰库。
- 光照：半球光 + 方向光（PCF 软阴影）+ 雾 + NeutralToneMapping。
- 自动道路板：组内等高相邻节点间自动生成路径甲板。

## 阶段三：角色与移动控制 ✅

- 原创角色「琉」：袍身 / 尖帽 / 提灯（带实时光源）全程序化建模。
- 动画：行走摆臂摇摆、待机呼吸与灯光脉动、转向阻尼、出场缩放、通关入梦。
- 点击移动：射线拾取可行走面 → 最近节点匹配 → A* 寻路 → 沿图移动。
- 乘坐系统：站在机关节点上随平台一起旋转 / 升降（引擎重锚定机制）。

## 阶段四：空间错觉与机关系统 ✅

- **端口重合连接**：跨组节点世界坐标重合（XZ<0.45、|dy|<0.4）才连通 —— 视觉对齐与真实连通由同一几何规则保证，谜题不依赖视角伪造。
- 机关类型：旋转（rotator）/ 平移（slider）/ 升降（lifter）/ 压力板（闩锁）/ 门锁（doorRequiresPlates）。
- 机关动画统一由引擎驱动，动画结束重建行走图；动画期间禁止新寻路。
- 把手交互：射线点击、悬停放大、旋转音效。
