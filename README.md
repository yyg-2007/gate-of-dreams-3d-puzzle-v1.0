# 幻境之门：梦境旅途

> **⚠️ 待开发版本（v1.0-dev）**：本项目为开发中的可玩原型，尚未正式发布。核心玩法与 8 个关卡已可完整通关，但仍在持续迭代中，功能与内容可能随时调整。

> 一款原创网页 3D 空间错觉解谜游戏。旋转建筑、连通不可能之路，穿越八座梦境。
> 提灯的旅人「琉」将在悬浮于云海之上的遗迹间，唤醒沉睡的机关，找到每一扇梦境之门。

## ✦ 立即游玩

```bash
npm install        # 首次安装依赖
npm run dev        # 启动开发服务器 → 浏览器打开 http://127.0.0.1:5173
```

生产构建与本地预览：

```bash
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 本地预览生产版本 → http://127.0.0.1:4173
```

关卡可通关性自动验证（状态空间 BFS 证明每关有解）：

```bash
npm run verify
```

## ✦ 玩法

| 操作 | 方式 |
| --- | --- |
| 移动 | 鼠标点击任意发光的可行走路面，角色自动寻路前往 |
| 旋转机关 | 点击悬浮的旋钮把手，桥梁/平台转动到下一状态 |
| 压力板 | 站上发光的圆形压力板，触发隐藏机关（闩锁式，永久生效） |
| 升降台 | 站上台面后点击把手（或踩上压力板），连人带台一起升降 |
| 视角 | `Q` / `E`（或右上角 ⟲ ⟳ 按钮）每按一次旋转 90°；滚轮缩放（0.65x ~ 1.8x） |
| 暂停 / 重开 | 右上角 Ⅱ 按钮，或键盘 `Esc`（暂停）、`R`（重开） |

**空间错觉规则**：所有道路连接由真实几何决定 —— 只有当两段道路的端口在空间中**精确重合**时它们才真正连通。旋转机关改变端口位置，看似断开的路会在对齐的一瞬间接通；看似可以走的方向，可能只是视觉的把戏。

> 视角旋转只是观察手段：道路连接按世界坐标计算，转不转视角、怎么转，谜题的解法都完全一致 —— 换个角度看看那些「不可能」的结构，正是乐趣的一部分。

## ✦ 八座梦境

1. **梦境入口** —— 唤醒沉睡的月牙桥
2. **旋转阶梯** —— 双弦梯绕塔螺旋上升
3. **消失的桥梁** —— 压力板唤回隐藏的滑桥
4. **天空之塔** —— 双升降台垂直爬塔
5. **镜像空间** —— 对称双塔与双头转桥，压力板为门充能
6. **倒转世界** —— 夜之领域，十字旋转桥通向倒悬之岛
7. **无尽回廊** —— 方形庭院四段机关的螺旋回路
8. **梦境终点** —— 全机关组合的终章，两块压力板开启巨门

## ✦ 项目依赖

**运行时**

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| react / react-dom | ^18.3 | UI 框架 |
| three | ^0.169 | WebGL 3D 渲染 |
| @react-three/fiber | ^8.17 | Three.js 的 React 渲染器 |
| @react-three/drei | ^9.114 | 相机等场景工具 |
| zustand | ^4.5 | 轻量状态管理（屏幕路由/设置/进度） |

**开发**

vite 5、typescript 5、@vitejs/plugin-react、tsx（脚本运行器）、@types/* 。

> 全部资源（角色、建筑、音乐、音效）均为**程序化生成**：
> 模型由参数化几何组合而成，音乐音效由 Web Audio 实时合成 —— 零外部资源文件、零版权风险、秒级加载。
> 架构中预留了 GLTF/GLB 加载位（`three/` 渲染层与数据驱动的 `MeshDef`），未来可无缝替换为外部模型资产。

## ✦ 目录结构

```
src/
  audio/       AudioEngine —— Web Audio 程序化音乐与音效
  levels/      关卡数据（types 数据模型 / builders 建造工具 / level1-8）
  store/       zustand 全局状态（屏幕、进度、设置）
  styles/      全局样式（UI、动画）
  systems/     核心系统
    graph.ts     行走图：世界矩阵、端口重合连接、A* 寻路
    engine.ts    关卡引擎：机关状态机、压力板、角色、通关判定
    save.ts      LocalStorage 存档
  three/       渲染层
    GameCanvas   画布总装 / 相机 / 光照 / 指针拾取
    LevelView    建筑组渲染 / 机关把手 / 压力板 / 标记
    Character    原创角色「琉」（程序化建模 + 动画）
    SkyDome/Water/Decor/Particles/Door  环境与特效
  ui/          全部界面（主菜单/选关/暂停/设置/结算）
scripts/
  verify-levels.ts  全关卡可通关性 BFS 验证
  debug-level.ts    单关连接诊断工具
```

## ✦ 部署

`npm run build` 产出完全静态的 `dist/` 目录，可部署到任意静态托管：

- **通用服务器 / Nginx**：将 `dist/` 上传至站点目录即可（构建使用相对路径 `base: './'`，支持任意子路径）。
- **GitHub Pages**：推送 `dist/` 到 `gh-pages` 分支。
- **Netlify / Vercel / Cloudflare Pages**：构建命令 `npm run build`，产物目录 `dist`。
- **itch.io**：将 `dist/` 打包 zip 上传（HTML 游戏）。

无需任何服务端；游戏进度保存在浏览器 LocalStorage。
